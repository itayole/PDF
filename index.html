PDF Editor — מדריך מהיר

פתיחת קובץ

לחץ על Open PDF…, גרור קובץ PDF על חלונית העמודים (שמאל), או לחץ על כפתור ה-+ בחלונית.

ניווט בין עמודים

גלול את חלונית התצוגה הגדולה (ימין) כדי לדפדף בין העמודים. לחץ על תמונה ממוזערת בשמאל כדי לעבור לעמוד ספציפי. השתמש בכפתורי Prev / Next או בגלגלת העכבר.

הוספת עמודים

  • לחץ על + שמופיע בין העמודים (או מעל / מתחת לרשימה) כדי להוסיף עמודים מקובץ PDF אחר.
  • גרור קובץ PDF על חלונית העמודים — אם כבר קיים מסמך, ייפתח חלון בחירת עמודים.
  • בחלון ההוספה: כברירת מחדל כל העמודים נבחרים. בטל בחירה של עמודים שאינך רוצה.
  • סמן Resize to match document כדי להתאים את גודל העמודים החדשים לגודל הקיים.

מחיקה, סידור מחדש ופעולות נוספות

לחץ לחיצה ימנית על עמוד כדי לקבל תפריט:

  • מחק עמוד — מחיקת עמוד אחד או בחירה מרובה (Ctrl+לחיצה / Shift+לחיצה).
  • סובב — ימינה או שמאלה.
  • שכפל — יוצר עותק של העמוד.
  • הוסף עמוד ריק — לאחר העמוד הנבחר.
  • Resize to smallest / largest — מאחד גדלים שונים בבחירה.
  • Extract → new PDF — שמירת העמודים הנבחרים כקובץ PDF נפרד.

גרור תמונות ממוזערות לשינוי הסדר. לבחירה מרובה: Ctrl+לחיצה, Shift+לחיצה, או Select all.

הוספת טקסט

לחץ על ＋ Text בסרגל, ואז לחץ על העמוד במיקום הרצוי. הטקסט מזוהה כעברית או אנגלית באופן אוטומטי (כולל ניפוי RTL).

שמירה

לחץ על Save… לפתיחת חלון האפשרויות: ניתן להוסיף מספרי עמודים (מיקום, פורמט, מספר התחלה). לחץ Save & download להורדת הקובץ הערוך.

צפייה מוגדלת

לחץ פעמיים על תמונה ממוזערת (או לחץ ימני ← View large) לצפייה בעמוד בחלון מוגדל. בחלון הוספת עמודים — לחץ על 🔍 בכרטיס העמוד לצפייה לפני הבחירה.

ביטול / חזרה

השתמש ב-↶ ↷ בסרגל, או במקשי Ctrl+Z / Ctrl+Y.

הערות

  • כל הפעולות מתבצעות בדפדפן בלבד — שום קובץ לא עולה לשרת.
  • PDF עם שכבת טקסט (searchable) — השכבה נשמרת בפלט.
  • קבצי PDF/A מזוהים ומוצג אזהרה — הפלט הוא PDF רגיל.

Release Notes

v0.38 — 2026

  • Fit page sizes: inserted pages auto-resize to match the document (default on in the insert picker); right-click selected pages → Resize to smallest or Resize to largest to unify mixed sizes. Scaling is aspect-ratio preserving, centered with white margins, live in the editor and in the saved file, and undoable.
  • Per-page render serialisation — hardens all rendering when the same page is requested concurrently (thumbnail + viewer).

v0.37 — 2026

  • Added Shiluv I²R link in the toolbar returning to the portal.
  • Added New button to clear the editor and start a fresh document.

v0.36 — 2026

  • Empty left pane now shows a "+" drop target with a prompt instead of a blank panel.
  • Fix (v0.36.1): pdf.js worker was served as application/octet-stream by nginx, preventing PDFs from opening on the deployed portal. Fixed by mapping .mjs to a JavaScript MIME type in nginx config.

v0.35 — 2026

  • Drag & drop a PDF onto the left pane: loads as the document when empty, or opens the insert picker targeting the drop position when a document is already open.
  • "+" insert zones at the top, bottom, and between every pair of thumbnails.
  • Insert picker defaults to all pages selected.

v0.3 — 2026 (initial release)

  • Two-pane workspace: scrollable thumbnail rail (left) + continuous full-size scroll viewer (right).
  • Open, delete, insert pages from other PDFs, reorder (multi-select drag), rotate, duplicate, insert blank pages, extract selection to a new PDF.
  • Add text overlays in English & Hebrew (RTL, embedded Noto Sans Hebrew font).
  • Page numbering on save (position, format, start value).
  • Searchable text layer preserved in the output.
  • PDF/A detection with a warning that the saved copy is a standard PDF.
  • Per-page zoom popup in the thumbnail rail and in the insert picker.
  • Undo / redo (Ctrl+Z / Ctrl+Y).
  • Deployable as a Docker / nginx container; all processing is client-side.
